# 服务器运维规范

## 一、日常巡检

生产环境服务器每天早上 9:00 前完成巡检，检查项包括：
CPU 使用率、内存占用、磁盘剩余空间、系统日志异常关键字。

磁盘使用率超过 **80%** 必须当天处理；超过 90% 立即告警。

## 二、变更窗口

所有生产环境变更只能在 **每周四 22:00 到次日 2:00** 进行。
变更前必须提交变更单，说明影响范围、回滚方案、验证方式。

紧急变更不受窗口限制，但需值班负责人与运维总监双签。

## 三、重启与停机

重启单台服务器需提前 2 小时通知相关业务方。
重启数据库主库需提前 24 小时通知，并安排在业务低峰期（凌晨 1:00 到 4:00）。

## 四、账号与权限

生产环境一律使用跳板机登录，禁止直连。
运维账号每 **90 天** 强制改密，离职人员账号在离职当天 17:00 前回收。

## 五、故障响应

P0 故障（服务完全不可用）：15 分钟内响应，2 小时内恢复。
P1 故障（部分功能受损）：1 小时内响应，8 小时内恢复。
P2 故障（体验问题）：次工作日响应。
