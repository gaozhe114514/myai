# 新员工入职指引

## 一、报到当天

携带材料：身份证原件、学历证书、离职证明、一寸照片 2 张、银行卡。
报到地点：前台登记后前往 3 楼人力资源部。

## 二、必办事项

1. 领取工牌（押金 50 元，离职时凭工牌退还）
2. 领取笔记本电脑（需签署设备领用单）
3. 开通企业邮箱与内部系统账号（**1 个工作日内**完成）
4. 加入部门群与全员群
5. 参加当天下午 15:00 的新人宣讲会

## 三、试用期

试用期 **3 个月**。考核在试用期结束前 5 个工作日启动，
由直属主管填写《转正评估表》。

试用期薪资为转正后的 80%，转正当月起调整为全额。

## 四、导师制

每位新员工配一名导师，为期 3 个月。
导师每月至少进行 2 次一对一沟通，并记录在案。
导师津贴为每月 300 元，转正后一次性发放。

## 五、常见问题

**工牌丢了怎么办？** 到人力资源部补办，补办费 20 元。
**电脑坏了找谁？** 提交 IT 工单，一般 4 小时内响应。
